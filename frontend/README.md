# Frontend

React/Next.js frontend application for the Price Predictor platform.

## Setup

```bash
npm install
npm start
```

## Available Scripts

- `npm start` - Run development server (port 3000)
- `npm build` - Build for production
- `npm test` - Run tests

## Features

- Product search and filtering
- Real-time price comparison
- Personalized alerts dashboard
- Cart management
- User authentication

## Environment Variables

```
REACT_APP_API_URL=http://localhost:8080
```
